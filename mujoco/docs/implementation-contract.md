# 구현 계약

이 과정은 바퀴형 로봇의 장애물 회피 과정을 Microduck 외형으로 바꾼 것이 아닙니다. 공식 이족보행 학습과 실물 런타임의 연결을 배웁니다.

## 기준 버전

기계가 읽는 정본은 `static/upstream-lock.json`입니다.

- 학습: `pollen-robotics/microduck_rl`, `53b8971b61baf5b7f3c16d135dd7cac37623de4b`.
- 런타임 문서: `pollen-robotics/microduck`, `5620aa214e6e304eec00d5c376ac81d3001fb7a3`. 판매 로봇을 이 커밋으로 강제 플래시하라는 뜻은 아닙니다.
- Python 3.12, `mjlab==1.3.0`; 나머지는 학습 저장소의 `uv.lock`과 `uv sync --frozen`으로 고정합니다.
- 기본 태스크 `Mjlab-Velocity-Flat-MicroDuck`; 원본의 BAM 액추에이터 모델, domain randomization, 관절 순서를 유지합니다.
- 모델 입력 `[1,61]` float32, 출력 `[1,14]` float32. 명령 블록은 twist 3 + head 4 + body 6입니다. 48개 고유상태 관측과 합쳐 61개입니다.
- projected gravity를 사용하는 기준 태스크입니다. raw accelerometer 기반 다른 정책과 혼용하지 않습니다.
- 제어 50 Hz는 실물 런타임 안에서 돌아갑니다. AWS는 학습·파일 저장에 사용합니다.

## 공식 온라인 시뮬레이터 연결

- 참가자용 연결 경로는 `static/visuals/biped-3d.html`을 유지합니다. 이 페이지는 [Pollen Robotics의 공식 Space](https://huggingface.co/spaces/pollen-robotics/microduck-simulator)를 안내하고 `https://pollen-robotics-microduck-simulator.hf.space`의 제공자 앱을 임베드합니다.
- 인터넷과 제공자 서비스 가용성이 필요합니다. 임베드가 차단되거나 열리지 않으면 공식 Space에 직접 접속할 수 있어야 합니다.
- Space는 제공자가 갱신하는 온라인 데모입니다. 위의 고정된 AWS 학습 환경·모델 인터페이스와 동일한 버전이나 설정이라고 전제하지 않습니다. 내 AWS GPU·체크포인트·실물 로봇·모터에 연결하지 않습니다.
- Space 메타데이터의 `RUNNING` 상태와 실제 iframe 렌더링 검증을 구분합니다. 브라우저 확인 결과는 [검증 기록](verification.md)에 남기며, 데모 실행은 아래 학습·평가·실물 단계의 통과 근거로 사용하지 않습니다.

## 자체 제작 관절 개념 뷰어와 3D 그림

- `static/visuals/joint-concepts-3d.html`은 오프라인 관절 연결 학습 도구입니다. Module 1과 Module 5에서 사용합니다. 공식 시뮬레이터의 `biped-3d.html` 경로는 유지합니다.
- 개념 뷰어는 6개의 표시용 관절과 임의의 치수를 사용합니다. 위의 실제 정책 출력 14개나 하드웨어 관절 제한을 재현하지 않습니다.
- Module 1·6·9의 그림은 같은 자체 도형으로 관절 연결, 관측과 행동, sim-to-real 차이를 설명합니다. 그림의 자세·값·지지 구조를 물리 계산 결과나 하드웨어 설계로 사용하지 않습니다.

## 서로 다른 확인 단계

1. 코드 테스트 통과: 보조 도구가 잘못된 파일·명령을 거부하는지 확인.
2. 학습 스모크 통과: 환경과 PPO 업데이트·체크포인트 저장이 실행됐는지 확인. 보행 성공이 아님.
3. 시뮬레이션 평가: 미사용 시드·명령에서 넘어짐, 이동·속도 추종, 비정상 관절 동작을 확인.
4. 모델 전달: 정식 exporter 사용, 입력·출력·유한값·해시 확인. 추론 검사는 보행 안전성 검사가 아님.
5. 실물 시험: 운영자가 하드웨어·펌웨어·정지 경로를 확인한 뒤 지지대, 정지 자세, 저속 보행 순서로 판단.

출력 수가 맞아도 관절 순서·정규화·액추에이터 모델이 틀리면 사용할 수 없습니다. 보조 ONNX 검사는 정규화 의미나 보행 품질을 증명하지 않습니다. `scripts/export.py`를 통해 정규화가 포함된 공식 그래프를 만들고 출처를 보존하세요.

## 배포 범위

교재에는 upstream 메시·MJCF·USD·CAD·사진·정책 가중치를 복사하지 않습니다. 공식 시뮬레이터는 제공자 앱을 임베드·링크하는 방식이며 해당 자산은 제공자 서비스에서 로드됩니다. 구조·학습 개념도는 자체 제작 자료로 유지합니다. 임베드·링크는 모델의 NC 조건을 해소하거나 상업 이용권을 부여하지 않습니다. 실제 학습 단계는 이용 권한을 확인한 참가자가 공식 저장소에서 고정 커밋을 받으며, `--asset-permission-confirmed` 다운로드 게이트를 유지합니다.

AWS 리소스는 사용자가 명시 배포합니다. 자동으로 다른 계정/기존 워크샵의 인스턴스를 시작하지 않습니다. 학습 가중치와 실물 시험 기록은 로컬 `artifacts/` 또는 private S3에 남기며 공개 교재 ZIP에 포함하지 않습니다.
