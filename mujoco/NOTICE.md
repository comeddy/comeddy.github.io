# 출처와 포함 범위

본 교재는 Microduck 공식 프로젝트를 이용하는 독립 교육 자료입니다. Pollen Robotics/Hugging Face 또는 AWS의 공식 워크샵 인증·승인을 의미하지 않습니다.

교재 소스에는 원본 로봇 모델·파생 CAD·메시·사전학습 가중치·제품 사진을 포함하지 않습니다. 구조·학습 개념도는 자체 제작 자료이며, AWS 서비스 아이콘을 사용하는 아키텍처 구성도는 실제 실습 리소스 관계를 설명합니다.

브라우저 체험은 [Pollen Robotics의 공식 Microduck 시뮬레이터](https://huggingface.co/spaces/pollen-robotics/microduck-simulator)를 임베드·링크합니다. 앱과 화면에 필요한 자산은 제공자 서비스에서 로드되며 교재 ZIP에 복사·재배포하지 않습니다. 인터넷과 제공자 서비스 가용성이 필요하고, 임베드가 열리지 않으면 공식 Space에 직접 접속합니다. 이 데모는 AWS 학습·참가자 체크포인트 재생·실물 로봇 또는 모터 연결을 수행하는 워크샵 도구가 아니며, 워크샵 학습 성공의 증거로 사용하지 않습니다.

공식 프로젝트의 소프트웨어·자산에는 해당 권리자의 조건이 적용됩니다. 자세한 근거는 [자산 라이선스](docs/asset-licensing.md)와 [출처](docs/sources.md)를 참고하세요. 임베드·링크는 모델의 NC 조건을 해소하거나 상업 이용권을 부여하지 않습니다. 실제 자산 다운로드·학습 전 이용 권한 확인은 계속 적용되며, 이 파일은 상류 자산에 새 권한을 부여하지 않습니다.

오프라인 관절 개념 뷰어와 중간 챕터의 3D 설명 그림은 자체 상자·원통 기하로 제작했습니다. 실제 Microduck의 CAD·메시·치수·관절 제한·동역학 데이터를 사용하지 않으며 실제 시뮬레이션 결과로 표시하지 않습니다.
