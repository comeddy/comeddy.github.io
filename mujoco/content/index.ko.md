# 클라우드에서 배우고, 내 로봇에서 움직이기

Microduck이 가상 공간에서 걷기를 연습하고, 내가 만든 모델을 실제 로봇에 옮기는 과정을 따라갑니다. 처음부터 완벽한 보행을 기대하기보다 **작은 확인 단계를 하나씩 통과하는 방법**을 배웁니다.

![AWS에서 학습하고 로봇 내부에서 실행하는 전체 구조](../static/images/aws-architecture.png)

## 이 과정을 마치면

1. 관찰·행동·보상이 무엇인지 설명할 수 있습니다.
2. AWS GPU에 접속하여 공식 시뮬레이션을 실행할 수 있습니다.
3. 학습 완료와 보행 성공의 차이를 알고 결과를 평가할 수 있습니다.
4. ONNX 모델의 형태와 해시를 검사하여 로봇으로 전달할 수 있습니다.
5. 실제 로봇에서 확인하고, 필요하면 공식 정책으로 복구할 수 있습니다.

## 먼저 알아둘 것

- 교재는 하루 분량으로 설계했습니다. 설치·학습 수렴·로봇 리허설에는 별도 시간이 들 수 있습니다.
- AWS 계정, GPU 한도, 인터넷, 로컬 터미널이 필요합니다. 실물 과정에는 조립·교정되고 공식 런타임이 설치된 Microduck이 필요합니다.
- 3D 모델의 실제 이용 권한은 [준비와 라이선스](module2-prerequisites/index.ko.md)에서 확인합니다.
- 이 배포본에는 학습된 모델이 없습니다. [검증 상태](../docs/verification.md)에서 실행한 검사와 아직 실행하지 않은 단계를 확인하세요.

## 세 가지 학습 경로

| 경로 | 하는 일 | 종료 지점 |
|---|---|---|
| 개념 체험 | 교재·그림·공식 온라인 시뮬레이터로 동작 이해 | AWS 실습 리소스 불필요, 온라인 체험에는 인터넷 필요 |
| 클라우드 실습 | AWS 구성, 실제 모델 설치, 학습·평가·ONNX | GPU 및 자산 이용 권한 필요 |
| 실물 확장 | 로봇 준비, 모델 전달, 지지대·저속 보행·복구 | 실제 로봇과 운영자 필요 |

[공식 온라인 Microduck 시뮬레이터 열기](../static/visuals/biped-3d.html). Pollen Robotics가 제공하는 브라우저 데모에서 화면의 안내에 따라 로봇 동작을 살펴보세요. 인터넷과 제공자 서비스 가용성이 필요합니다. 교재 안에서 열리지 않으면 [Hugging Face Space에 직접 접속](https://huggingface.co/spaces/pollen-robotics/microduck-simulator)하세요.

이 데모는 AWS GPU에서 학습하거나 내 체크포인트를 재생하는 실습과 별개입니다. 실제 로봇·모터에 연결하지 않으며, 데모의 움직임이 이 워크샵의 학습 성공을 증명하지 않습니다. 교재는 제공자 앱을 연결하고 메시·가중치·사진을 재배포하지 않습니다. 공식 데모의 연결은 상업 이용 허가를 뜻하지 않으며, 다운로드·학습 전 [자산 이용 조건](module2-prerequisites/index.ko.md) 확인은 그대로 필요합니다.

**기억할 점:** 모델 파일이 생겼다는 사실만으로 실제 로봇에 올릴 준비가 끝난 것은 아닙니다.
