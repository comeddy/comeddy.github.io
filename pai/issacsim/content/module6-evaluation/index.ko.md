# 6. 처음 보는 공간에서도 움직일까?

**시간: 35분 · 실행 위치: AWS EC2**

이번에는 교사가 아니라 학습한 모델이 속도를 결정합니다.
학습과 다른 seed를 사용합니다. 정지 검사는 모델 뒤에서 계속 동작합니다.

## 6-1. 모델로 주행

```bash
cd ~/physical-ai-isaac-aws
ACCEPT_EULA=Y bash scripts/cloud/run-headless.sh \
  static/code/sim/run_sim.py \
  --mode evaluate --episodes 5 --steps 600 --seed 900 \
  --policy /output/policy.npz \
  --output /output/evaluation.json
cat /opt/isaac-workshop/output/evaluation.json
```

평가 JSON의 `summary`와 `episodes`를 봅니다.
충돌, 근접 상황, 실제 이동 거리, 정지 검사 개입 비율을 따로 기록합니다.
**움직이지 않아서 충돌이 0인 모델은 성공한 주행 모델이 아닙니다.**

실제로 기록된 CSV 궤적을 SVG 그림으로 만듭니다.

```bash
ACCEPT_EULA=Y bash scripts/cloud/run-headless.sh \
  static/code/render_trace.py \
  --report /output/evaluation.json --csv /output/evaluation.csv \
  --output /output/evaluation.svg
```

모듈 3처럼 프리뷰 서버와 SSH 터널을 열고 `evaluation.svg`를 봅니다.
파란 선은 실제 물리 엔진에서 기록한 경로, 초록색은 시작, 빨간색은 종료 위치입니다.
PNG 한 장은 장면만 보여주므로 연속 주행 판단에는 CSV 궤적을 사용합니다.

## 6-2. 실물 단계로 넘어갈 조건

아래 값은 교육용 리허설 기준이며 산업 안전 인증 기준이 아닙니다.

| 확인 | 통과 기준 |
|---|---|
| 실행 | `summary.completed_episodes`가 5, 조기 정지 없이 완료 |
| 충돌 | `summary.collision_episodes`가 0 |
| 이동 | 각 에피소드 `path_length_m` 1m 이상, `net_displacement_m` 0.3m 이상, 궤적상 정체 없음 |
| 근접 | 센서 최소거리와 프리뷰 검토; 반복 근접 시 데이터 보완 |
| 정지 검사 | 개입 비율 5% 미만을 목표; 초과하면 원인 조사 |
| 입력 | 유효하지 않은 센서나 NaN 출력 없음 |

임계값은 코드의 실물 안전성을 보증하지 않습니다.
같은 모델이라도 실제 센서와 마찰 조건이 달라 별도 실물 확인이 필요합니다.
충돌은 차체·바퀴·caster와 장애물 사이의 PhysX 접촉으로 판단합니다.
근접 거리는 차체를 반지름 0.14m 원으로 근사한 값이며 실제 접촉과 구분합니다.

### 실제 실행에서 배운 점

2026-09-09 AWS 리허설에서는 5개 평가가 모두 완료되고 기록된 충돌은 0이었지만,
두 환경에서 측면 장애물과의 여유가 부족했습니다. 보수적 차체 원의 최소 여유는 −0.0132m였고,
다른 환경에는 4.8초의 낮은 이동 구간이 있었습니다. 따라서 이 모델의 **실물 바닥 주행은 보류**했습니다.
전방 센서만 검사하면 측면 근접을 놓칠 수 있습니다. [전체 검증 기록](../../docs/verification.md)을 참고해
수치 조건과 궤적·근접 조건을 함께 판단하세요. 기준을 통과하지 못한 모델은 다음 장의 준비 문서를
읽거나 모터를 사용하지 않는 그림자 검사를 할 수 있지만, 실물 자율주행에 사용하지 않습니다.

## 6-3. 실패를 해석하기

| 관찰 | 먼저 볼 것 |
|---|---|
| 계속 정지 | 전방 거리, 입력 순서, 정지 검사 이유 |
| 같은 자리에서 빙글빙글 | 교사의 정체, 막다른 환경, 직진 데이터 부족 |
| 한쪽으로만 회전 | 좌·우 데이터 비율, 각도 부호 |
| 장애물에 자주 접근 | 교사 회전 시작 거리, 센서 높이·오프셋 |
| 학습 오차는 작은데 충돌 | 닫힌 고리 주행에서 누적된 오류, 데이터 범위 부족 |

센서 높이와 장애물 배치를 고치고 다시 수집·학습하는 것이 실습의 일부입니다.
통과 기준을 낮춰서 다음 단계로 넘어가지 마세요.

**완료 확인:** 평가 기록과 프리뷰를 보고 이동·충돌·개입을 모두 설명할 수 있습니다.

**기억할 점:** 한 프레임의 예측 정확도보다 연속 주행에서의 동작을 확인해야 합니다.
