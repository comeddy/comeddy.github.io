# 0. 센서 → 판단 → 행동

**시간: 20분 · 실행 위치: 교재**

일반 챗봇은 문장을 만듭니다. 이 실습의 AI는 센서 숫자를 읽고 **얼마나 앞으로 갈지,
얼마나 회전할지**를 만듭니다. 그 숫자가 실제 바퀴에 전달되므로 Physical AI입니다.

:image[그림 1. 센서가 거리를 읽고 AI와 정지 검사를 거쳐 바퀴를 움직이는 반복 과정]{src="/static/images/concepts/physical-ai-loop.png" width=1200}

바퀴가 움직이면 주변 물체와의 거리가 달라집니다.
로봇은 새 거리를 다시 읽고 판단하므로 이 과정이 계속 반복됩니다.

## 다섯 단어만 먼저 이해하기

| 단어 | 쉬운 뜻 | 이 워크샵에서 |
|---|---|---|
| 시뮬레이터 | 컴퓨터 안의 실험실 | NVIDIA Isaac Sim |
| 관측값 | 로봇이 지금 보고 있는 것 | 주변 12방향의 장애물 거리 |
| 정책(policy) | 관측값을 행동으로 바꾸는 함수 | 작은 신경망 |
| 모방학습 | 교사의 예시를 보고 따라 배우기 | 거리와 정답 속도 쌍으로 학습 |
| Sim-to-real | 가상에서 배운 것을 실제에 옮기기 | AWS 모델을 Raspberry Pi에 복사 |

Isaac Sim은 현실에 가까운 가상 세계와 물리 계산을 제공합니다.
Isaac Lab은 Isaac Sim 위에서 강화학습 등을 구성하는 도구입니다.
**기본 실습은 Isaac Sim + NumPy 모방학습**이므로 Isaac Lab을 설치하지 않습니다.

## 로봇의 입력과 출력

거리 센서는 360도를 읽습니다. 수백 개의 거리 숫자를 30도씩 12구역으로 묶고,
각 구역에서 가장 가까운 장애물 거리를 선택합니다.

예를 들어 “앞쪽은 2m, 왼쪽은 1m, 오른쪽은 0.3m”라면,
교사는 오른쪽 장애물을 피해 왼쪽으로 돌도록 예시를 만듭니다.
신경망은 이런 예시를 여러 번 보고 비슷한 판단을 배우게 됩니다.

출력은 두 숫자입니다.

| 값 | 단위 | 예시 |
|---|---|---|
| `linear.x` | m/s | `0.08`: 초당 8cm 전진 |
| `angular.z` | rad/s | `0.3`: 왼쪽으로 회전 |

기본 코드의 최대값은 전진 `0.12m/s`, 회전 `0.6rad/s`입니다.
실물 첫 주행은 이보다 낮게 제한합니다.

## 학습과 정지 검사는 별개

신경망은 틀릴 수 있습니다. 코드에는 학습 모델과 별도로 정지 검사가 있습니다.
센서가 오래되었거나, 입력값이 이상하거나, 전방 장애물이 가까우면 속도를 0으로 만듭니다.
하지만 프로세스나 통신 자체가 멈추면 Python 코드는 정지를 보낼 수 없습니다.
따라서 모터 컨트롤러의 명령 타임아웃도 실제로 검증합니다.

## 오늘의 성공 기준

1. 내 시뮬레이션에서 생성한 데이터로 모델 파일을 만든다.
2. 학습에 사용하지 않은 환경에서 움직임과 개입 횟수를 확인한다.
3. 실제 센서 입력으로 모델을 실행하되 처음에는 모터에 연결하지 않는다.
4. 바퀴를 띄운 상태에서 정지 동작을 확인한다.
5. 넓고 평평한 공간에서 30초 단위로 천천히 주행한다.

**완료 확인:** “가상 데이터는 AWS에서 만들고, 실제 주행 판단은 로봇에서 한다”를 설명할 수 있습니다.

**기억할 점:** 모델의 정확도 수치가 높아도 실물 주행 검증은 필요합니다.
