## 실제 Isaac Sim 실행과 학습

실행 이미지는 `nvcr.io/nvidia/isaac-sim:5.1.0`, digest는
`sha256:f3563cb2ba0c18af0b2fb321360dcb73a917b899f879e3213623d6bee484fa54`입니다.
호스트 Ubuntu는 22.04, 컨테이너 내부 Ubuntu는 24.04.2입니다.
GPU는 카메라 렌더링에 사용했고, 물리 엔진은 코드에 지정된 **CPU PhysX**로 실행했습니다.
학습은 같은 컨테이너의 NumPy MLP이며 GPU 학습이나 강화학습은 아닙니다.

### 접촉 감지의 별도 확인

학습·평가와 분리한 진단 장면에서 차체가 장애물에 닿을 때 **12.105N**의 차체 행 응답을 확인했습니다.
차체·좌우 바퀴·보조바퀴의 활성 CollisionAPI 형상과 4×12×3 접촉 행렬도 확인했습니다.
보조바퀴 아래에 기존 장애물을 1mm 겹치게 놓은 별도 시험에서는 36 물리 스텝 동안
**보조바퀴 행만 최대 9.622N**으로 반응했습니다. 첫 진단의 보이지 않는 형상 경계 조회 문제를
수정한 뒤 JSON의 `CASTER_POSITIVE_RESPONSE_OBSERVED`와 실제 행별 값을 검사했습니다.

이는 검사한 차체·보조바퀴 접촉 사례의 양성 반응을 확인한 결과입니다. 좌우 바퀴 각각의
양성 접촉 시험, 모든 충돌 상황, GPU 물리 계산, 실물 정지 성능을 검증한 것은 아닙니다.
이 진단 데이터는 학습·평가 CSV에 넣지 않았으며 아래 모델의 근접 문제를 해결하지 않습니다.

**실물 바닥 자율주행 진입: 보류(NO-GO).** 경로 1m·순이동 0.3m 이상과 개입 5% 미만의
수치 조건은 충족했지만, 근접·정체를 검토하는 정성 조건을 통과했다고 판단하지 않습니다.

- seed 904: 근접 19스텝, 최소 여유 **0.0300m**.

68/3,000스텝(2.27%)에 근접 상황이 포함됐습니다. 교사·데이터의 측면 회피를 보완하고,
차체 범위를 고려하는 보호 로직을 검토한 뒤 같은 장면과 추가 미사용 seed에서 재평가해야 합니다.
이번 모델은 학습 결과 분석과 격리된 그림자 실행용으로 보관합니다. 실물에서는 센서 정렬,
받침대 위 명령 만료·정지 시험을 먼저 수행하며, 이번 실행 결과만으로 바닥 자율주행을 승인하지 않습니다.

## Linux ARM에서 실행한 로봇 코드 검사

Docker Desktop의 격리된 `linux/arm64` 컨테이너에서 Ubuntu 22.04.5, Python 3.10.12,

`sha256:75dd3aba34a3838dadbb31a9f7bef769bdfa8713e6cec686fc868db2981b0987`입니다.
TurtleBot3는 교재에 고정된 `90a68bd2e3c61c12966779da89d8eeaec82730e9` 소스를 사용했습니다.

장비 준비 문서의 첫 빌드는 탐색 패키지를 제외하고 `turtlebot3` 메타패키지를 남겨 실패했습니다.
메타패키지도 제외하도록 명령을 수정했습니다. 원본을 다시 추출하고 기존 build/install/log가 없는
깨끗한 환경에서 **7개 패키지 빌드가 50.4초에 완료**됐습니다. 새 AArch64 실행 파일의
링크·공유 라이브러리 해석과 watchdog 헤더 포함까지 확인했습니다.

DDS 검사는 합성 LaserScan과 검사 전용 모델을 사용했습니다. `/cmd_vel`과 센서는 격리된 컨테이너 안에만 존재했습니다.
관측한 정지 명령 도착 시간은 물리적 모터 정지 시간이나 보장된 실시간 기한이 아닙니다.
Pi OS 설치, LDS·USB·OpenCR 통신, 펌웨어와 모터의 실제 동작은 이 결과에 포함되지 않습니다.

### AWS에서 생성한 모델을 ARM으로 옮겨 실행

앞서 학습한 실제 `policy.npz`(4,155 bytes)를 ARM64 ROS 환경으로 옮기고, 원본·복사본·컨테이너에서
같은 SHA-256을 확인한 뒤 로드했습니다. 이 검사는 새 모델을 만들거나 학습을 반복하지 않았습니다.

- Linux ARM64에서 로드·재로드·단일/배치 추론과 MLP 수식 대조가 통과했습니다.
- 고정 입력 8종의 macOS 대비 최대 절대 오차는 약 **1.33×10⁻¹⁵**였습니다.
- 실제 DDS로 합성 LaserScan을 전달하자 디바이스 속도 제한·정지 검사를 적용한 모델 예측과
  동일한 그림자 출력이 관측됐습니다.
  속도는 디바이스 제한인 0.05m/s 이내였고, `/cmd_vel` publisher와 수신 메시지는 모두 0이었습니다.
- 센서 입력을 끊은 뒤 약 0.508초에 0 출력을 관측했고 입력 복구 후에도 정지가 유지됐습니다.
  이 수치는 컨테이너의 메시지 관측 시간으로, 물리적 정지 시간은 아닙니다.
- SIGTERM 최종 0 출력과 종료 코드 0을 확인했습니다. 검사 컨테이너는 제거했습니다.

이는 실제 학습 파일의 전송·추론 호환성과 그림자 출력 검증입니다. 위의 **실물 바닥 주행 NO-GO**
판정과 실물 센서·OpenCR·모터 미검증 상태는 유지합니다.
